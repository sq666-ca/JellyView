# 第01版 · 导入与分类说明

## 订阅与配置

- [M3U订阅](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/LibreTV-HD-Only.m3u)：复制地址，在客户端的“添加直播源／列表地址”中填写。
- [JSON配置](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/LibreTV-HD-Only.json)：支持此格式的客户端可复制完整JSON到配置导入框，也可直接填写配置URL。

JSON的`liveSources[].url`与兼容字段`live[].url`均指向同一公网M3U。`version: 2`是配置格式版本，直播资料为第01版。本机预览地址不用于正式订阅，无需启动本机审核服务。

这些资源结合[LibreTV开源项目](https://github.com/LibreSpark/LibreTV)的订阅接入方式整理，供JellyView以及支持相应格式的LibreTV版本使用。只有M3U入口的客户端直接使用M3U地址；配置导入能力以所用版本为准。

## 地区与分类

中国大陆频道继续分为央视频道、卫视频道。中国香港频道、中国台湾频道按综合、新闻、动漫、电影、剧集、纪录片、综艺、音乐浏览。海外频道先按美国、俄罗斯、英国、加拿大、德国、法国、意大利、日本、韩国排列，再按八类浏览。

M3U标准分组保留“香港频道、台湾频道、海外频道”。国家、内容类型、语言、版本、画质与优先级另用扩展字段保存。完整层级显示需要客户端读取这些字段；部分客户端只展示平面列表。此次参考解析器检查可读243路视频与69个网页入口，综合和优先排序仍需相应软件实现，不把资料更新写成软件界面已完成。

频道资料、节目依据与实际播放地址分开记录，部分地址为公开第三方转播。画质来自实际解码，不由台名中的HD或4K推断；传输尺寸不等于所有老片的原生制作画质。采样不保证全天、跨地区或长期稳定，具体状态见[复测说明](../checks/01-243路画质与复测说明.md)。
