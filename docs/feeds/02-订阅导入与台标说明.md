# 第02版 · 订阅导入与台标说明

发布2026-11-03，接替第01版。默认使用204路精选；需要更多频道时再添加34路扩充，两份视频不重复。

## 添加订阅

1. 已使用原M3U地址：在客户端刷新订阅，地址不变。
2. 新增默认精选：复制[原固定M3U地址](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/LibreTV-HD-Only.m3u)到直播列表地址。
3. 使用配置导入：[精选JSON](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/LibreTV-HD-Only.json)可填写URL，也可复制全文粘贴。具体导入方式依客户端版本。
4. 扩充列表：[扩充M3U](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/JellyView-Expansion.m3u)或[扩充JSON](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/JellyView-Expansion.json)。

`JellyView-Selected.m3u`与`LibreTV-HD-Only.m3u`内容相同，二选一即可。两个精选JSON都引用原固定M3U，避免因别名重复添加。JSON格式版本`2`与直播资料编号02是独立概念。

本模块结合[LibreTV](https://github.com/LibreSpark/LibreTV)的M3U订阅与[LibreTV-SourceList解析约定](https://github.com/LibreSpark/LibreTV/blob/main/src/lib/source-list.ts)整理：`liveSources`供LibreTV读取，`live`供JellyView读取，`sources`为空，不添加点播接口。

标准M3U提供视频地址、`tvg-logo`、频道ID和基础分组。`jellyview-area`、国家、类别、画质、官网等为扩展字段；`#JELLYVIEW-WEB-CHANNEL:`用于网页入口。其他播放器可能忽略这些扩展，只显示视频。

## 地区与分类

大陆频道按央视、卫视；香港频道、台湾频道各自按内容筛选。海外频道先选美国、俄罗斯、英国、加拿大、德国、法国、意大利、日本、韩国，再选综合、新闻、动漫、电影、剧集、纪录片、综艺、音乐。

“动画、纪实、电视剧”兼容为“动漫、纪录片、剧集”。不设置每类1台或4台截断。官网是打开方式，跟随同一套分类；同台视频已有官网操作时不再重复生成网页卡片。网页点击打开原站，不交给直播播放器。

## 台标与简称

377个条目中371项有识别图，合计361份不重复原始图片。图片随仓库发布，订阅使用公网Raw链接；来源、身份与SHA-256见`libretv/catalog/logos.json`。部分为所属机构或共用品牌图，不假称每台都有独立设计的标识。

保留原图比例和颜色，用固定槽位等比完整显示；透明白字及深色标识需要适合的底色。图像失败应回退频道简称，不回退国家名。视频提供`jellyview-short-name`，网页提供`shortName`；是否读取及如何显示以客户端为准。
