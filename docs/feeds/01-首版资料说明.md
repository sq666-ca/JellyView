# 第01版 · 主流优先与分类扩充

日期：2026-10-28。状态：已发布。**这是新建JellyView仓库的首个公开资料版本，没有上一公开版。** 本地132路稿只用于筛选对照，不占本仓库版号；当前243路稿经审阅后作为第01版接入。

当前包含243路视频和69个独立官网入口。中国大陆51路保持原有频道与线路；中国香港、中国台湾以及海外国家增加“综合”，与新闻、动漫、电影、剧集、纪录片、综艺、音乐组成八类。每个地区/国家、每个内容分类最多4个独立频道，优先主流机构，再补不同节目库与专业频道。

英国Most Haunted灵异纪实保留1080P线路；这是同一节目品牌的专台，会更换不同期数。加拿大HauntTV继续收录，定位为多部灵异及超自然题材的纪实与实境内容。香港增加港台电视31、KIX、黄金翡翠台、亚洲剧台；单节目、混合内容和国际/地区分发版本均单独注明。

测试记录包括实际解码尺寸、扫描方式、时间、抽帧哈希与直播清单推进。港台及海外192路有本轮记录，其中191路取得正常节目样本，ARD德国一台部分节目受地区限制；大陆51路沿用原记录，CCTV-10仍标为台标待核。173路记录为1080P、1路2160P、7路720P–1080P浮动、62路720P。

本地基线中加拿大Retro Crime Drama、Nosey原线路未取得可解码视频，德国原Pluto剧集线路实际低于720P，暂留待复测；MovieSphere改用通过检查的720P线路。Top Gear排除节目不符的1080P候选，保留台标与节目相符的720P线路。这些是本地筛选记录，不是本仓库公开版之间的升级记录。

资料编号与软件版本、JSON格式版本分别管理。软件源码与发行资料整理接入中；本次只发布直播模块，未纳入软件源码或安装器。
