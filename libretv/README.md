# JellyView直播订阅

第01版 · 主流优先与分类扩充 · 2026-10-28。当前243路视频、69个独立官网入口。

## 直接使用

- **[M3U订阅](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/LibreTV-HD-Only.m3u)**
- **[JSON配置](https://raw.githubusercontent.com/sq666-ca/JellyView/main/libretv/feeds/LibreTV-HD-Only.json)**

在“添加直播源”中填写M3U地址；支持配置导入的客户端也可粘贴JSON全文或填写JSON地址。JSON内部已经指向同一公网M3U，无需本机服务。

本模块结合[LibreTV开源项目](https://github.com/LibreSpark/LibreTV)的订阅接入方式整理，提供M3U和兼容JSON配置。具体配置与分层显示依客户端支持，详见[导入说明](../docs/feeds/01-导入与分类说明.md)。
